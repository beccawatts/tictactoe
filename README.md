# Tic Tac Toe
A Tic Tac Toe game, made with C++ for a Codecademy open-ended project in the [C++ Course](https://www.codecademy.com/enrolled/courses/learn-c-plus-plus). The aim was to utilise the functions, loops, and vectors.

I used function specific and header files for organisation in this project and made use of vectors to create the Tic Tac Toe grid. This project helped me explore the use of loops and vectors, as well as strengthening my confidence in functions and using them across multiple files.
